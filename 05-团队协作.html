05 · 团队协作与文档规范

车系品牌开发跟进表规范

目的：为确保后续能用通用的脚本读取所有品牌的跟进表，特做以下规范。

1. 第一张工作表 —— ECU总表

  • 工作表名称必须为 ECU总表。
  • 内容：当前车系所有诊断内容。
  • 列名如下（后面按需新增列）：
⛔ 禁止：使用 sheet1 或其他名称。脚本按表名 ECU总表 读取。
列名描述
Brand品牌
Model车型
System系统
EcuECU
Protocol诊断协议
pin诊断针脚
baudrate波特率
reqID请求ID
resID响应ID
开发情况开发状态

2. 第二张工作表 —— 项目计划

  • 工作表名称必须为 项目计划。
  • 内容：开发任务拆分。
  • 列名如下（后面按需新增列）：
⛔ 禁止：使用 sheet2 或其他名称。脚本按表名 项目计划 读取。
列名描述
序号任务序号
内容任务描述
负责人负责人姓名
截止时间YYYY-MM-DD
开发状态任务开发状态；必须使用固定分类，便于筛选
版本号对应软件版本号

3. 第三张工作表 —— 特殊功能跟进表

  • 工作表名称必须为 特殊功能。
  • 内容：所有特殊功能清单。
  • 列名如下（后面按需新增列）：
⛔ 禁止：使用其他名称。脚本按表名 特殊功能 读取。
列名描述
车系车系
车型车型
系统系统
ECUECU
功能名特殊功能名称
底层索引用于开发者快速定位该功能在底层文件的位置
工程索引用于开发者快速定位该功能在开发项目文件的位置
开发情况开发状态；必须使用固定分类，便于筛选
版本号对应软件版本号

4. 后续工作表

  • 第四张及以后可按需补充其他信息。
  • 不得占用 ECU总表 / 项目计划 / 特殊功能 三个固定名称。
